# PSAT 헌법 기출 문제 풀이 App

HTML, JavaScript, CSS로 제작된 가벼운 PSAT 헌법 기출문제 풀이 웹 애플리케이션입니다.

## 기능
- **연도별 풀이**: 2017~2024년 기출 문제를 연도별로 풀 수 있습니다.
- **랜덤 모의고사**: 전체 기출 문제 중 25문제를 무작위로 추첨하여 풉니다.
- **오답 복습**: 최근 7일간 틀린 문제를 다시 풀어볼 수 있습니다.
- **채점 및 기록**: 점수 추이 그래프와 Top 10 랭킹을 제공합니다.
- **PWA 지원**: 모바일에서 '홈 화면에 추가'하여 앱처럼 사용할 수 있습니다.

## 실행 방법

### 1. 웹 서버 이용 (권장)
Service Worker(PWA) 기능은 보안 정책상 `http://localhost` 또는 `https` 환경에서만 동작합니다.
VS Code의 'Live Server' 확장 등을 사용하여 `index.html`을 실행하는 것을 권장합니다.

### 2. 로컬 파일 실행
단순 문제 풀이 기능은 `index.html` 파일을 크롬/사파리 등 브라우저로 직접 열어서(`file://...`) 사용할 수 있습니다. 단, PWA 설치 기능은 작동하지 않을 수 있습니다.

## 데이터 업데이트
새로운 기출문제 JSON 파일이 추가되면, 아래 명령어로 `data.js`를 갱신할 수 있습니다.
```bash
node build_data.js
```

## 파일 구조
- `index.html`: 메인 실행 파일
- `app.js`: 애플리케이션 로직 (IndexedDB, 퀴즈 로직 등)
- `style.css`: 스타일 시트
- `data.js`: 문제 데이터 (JSON 변환됨)
- `sw.js`: PWA Service Worker
